# Affordance Encoder Head

Intentional, agent-level actions only. Emits one primary affordance (optionally a second) or `__null__` when no suitable action exists. Event, result, causal, and light verbs are firewalled to prevent semantic collapse.

## Purpose
Answers: “What intentional action or interaction defines how this memory should be navigated?” Affordance is stricter than Attribute; null is common and correct when only descriptions or events are present.

## Behavior
- Discovers open-class verbs in the record's dependency parse (VERB tokens of the rule parser's ParsedDocument, `context["spacy_doc"]`). A record without a parse is parsed with the rule parser first (`src/encoders/record_parse.py`).
- Salience: prefers sentence `ROOT`, `conj` of root, `xcomp`, `ccomp`; minor weight for other verbs. Without any parse (the parse failed) predicate mode emits `__null__` and selected mode reads verbs by regex.
- Agency/intent bonuses: subject, direct object, purpose clause (“to …”).
- Penalties: passive voice, light verbs (be/have/do), event/result/causal verbs (firewall).
- Selection: adaptive elbow/cluster filter with absolute + soft mins; hard cap `max_affordances` (defaults to 1, never exceeds 2). If nothing clears thresholds, emits `__null__`.

## Emit modes

`emit_mode` (env `NAM_AFFORDANCE_EMIT`, default `predicate`):

- **predicate** -- one address per distinct predicate value in the text
  (`predicates.py`: repaired lemma, shared synonym fold, curated or learned
  phrasal value, verb + object idiom value; copular `classify`/`describe`
  only with `emit_copular`, off by default), each with the token positions it
  occurs at. The extractor drops discourse-frame verbs (`frame_verbs`
  always, `frame_verbs_positional` in a framing position), idioms without a
  value ("shed light", "play a role"), aspectual verbs that govern another
  verb (also across an object: "helps us appreciate"), and participles inside
  a noun phrase ("a landlocked country"). The bundler links every entity
  mention to its own predicate (`addressing/predicate_linking.py`); a mention
  it cannot link stays empty (no dependency-walk or nearest-verb fallback on
  predicate output). Each predicate passes the config firewalls
  (+ `FIREWALL_ONTOLOGY_EXEMPTIONS`), is scored with the config weights,
  `ONTOLOGY_RELEVANCE` and NER relevance (a passive verb loses at most half
  its base weight), and is kept if it clears `soft_min_confidence`. `absolute_min_confidence`, the primary/secondary
  rule (`secondary_delta`, `secondary_min_confidence`), `elbow_gap`,
  `cluster_tolerance` and `max_affordances` are NOT applied: they pick 1-2
  verbs per record, and the bundler needs a value per entity (per-record
  selection left 56% of bundles empty on the wiki sample). Fan-out is bounded
  instead by `max_predicate_values` per record and `MAX_AFFS_PER_BUNDLE` (3)
  per bundle. `config_summary()["selection_knobs_applied"]` lists the knobs
  the active mode uses.
- **selected** -- the original primary + optional secondary verb per record.

The predicate lexicon (verb bases, synonyms, phrasal values, value counts by
ontology) lives in the category store under `vcat::` (`predicate_store.py`);
counters merge across pods (`storage/merge.py`); seed rows carry a seed
version (`storage/seed_version.py`), so a changed seed artifact re-seeds the
seeded rows when a head pod starts.

The synonym fold (`data/verb_synonyms.json`) is generated by
`build_synonyms.py` (WordNet 3.0): two verbs fold only when they share their
dominant sense with evidence (SemCor share >= 60% with a Wilson lower bound
>= 0.5; a verb without counts only if it has one sense; the canonical counted
in that sense), minus the meaning-changing folds in `_KEEP_DISTINCT`. Words an
older table folded are listed in `data/verb_synonyms_unfolded.json` and seeded
as identity synonym docs, which replace the old fold in a store seeded from
that table. Records ingested under an older table keep its values until they
are re-ingested.

## Configuration
Key options in `config.py`:
- `max_affordances` – fanout cap (default 1, clamped to 2).
- `weights` – base weights and bonuses/penalties (`root`, `conj_root`, `xcomp`, `ccomp`, `regex`, `subj_bonus`, `dobj_bonus`, `purpose_bonus`, `passive_penalty`, `event_penalty`, `light_penalty`).
- `absolute_min_confidence`, `soft_min_confidence`, `elbow_gap`, `cluster_tolerance` – adaptive selection thresholds.
- Blocklists: `event_verbs`, `result_verbs`, `causal_verbs`, `light_verbs`,
  `frame_verbs`, `frame_verbs_positional`.
- `emit_copular` (env `NAM_AFFORDANCE_COPULAR`, default off).

## Usage
```python
from src.encoders.registry import EncoderRegistry, MultiHeadEncoder

registry = EncoderRegistry()
registry.discover_encoders()
registry.enable_heads(["affordance"])

encoder = MultiHeadEncoder(registry)
results = encoder.encode("Tyler repaired the pump after the failure.")
aff = results["affordance"].addresses
print([(a.concept, round(a.confidence, 2)) for a in aff])
```

## Output
Each `SemanticAddress`:
- `head_type`: `affordance`
- `concept`: verb lemma or `__null__`
- `confidence`: navigational suitability (0–1)
- `metadata.method`: `"predicate"` (predicate mode), the verb's role (`"root"`, `"xcomp"`, ... in selected mode), or `"null"`
